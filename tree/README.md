# شجرة السند

نموذج HTML مستقل، يبدأ بالصحابي ثم يتطوّل عند فتح كل راوٍ. يمكن إبقاء أكثر من فرع مفتوحاً، وطيّ الفروع، أو فتح جميع المسارات حتى نهايتها. الخطوط تصِل العقد الفعلية وفق بادئة السند، ولا تربط كل راوٍ بجميع رواة الطبقة التالية.

الشجرة تمتد أفقياً عند تعدد الفروع وعمودياً عند زيادة الخطوات، ضمن مساحة تمرير بالاتجاهين. زر العودة للجذر يعيد موضع العرض.

التحقق: عائشة ثم عروة ثم الزهري ثم مالك حتى يحيى بن قزعة، وفتح جميع فروع أسامة للوصول إلى 7 خطوات، ثم طيها إلى الجذر. البيانات أولية من الصور الثلاث وليست تفريغاً كاملاً معتمداً.
