# أطلس الأسانيد

نموذج HTML مستقل لتجربة خريطة ثنائية الأبعاد، وليس حزمة Flutter. اسحب بالفأرة أو اللمس للتحريك، واستخدم العجلة أو الأزرار أو إيماءة الإصبعين للتكبير.

الجزر الفرعية تُكشف هندسياً داخل مكان الجزيرة الأصلية عندما يصبح نصف قطرها المعروض 180 بكسل أو أكثر. التصغير يعيد عرض الجزيرة الأم. الضغط على جزيرة يقرّب الكاميرا إليها. لا تتغير الصفحة أو يُستبدل المشهد عند عبور العتبة.

البيانات نفس المسارات الأولية الـ41، مع إنشاء عقدة منفصلة لكل بادئة سند لحماية الفروع المشتركة. الرسومات كلها SVG داخل الملف.

التحقق: كشف عروة بعد عائشة، ثم الزهري وفروعه الثمانية، إعادة ظهور الزهري عند التصغير، وتحريك الفروع 50 بكسل أفقياً و60 عمودياً بالفأرة. إيماءات الإصبعين مبرمجة وتحتاج اختبار جهاز فعلي.
