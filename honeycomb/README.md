# خلايا الأسانيد — الواجهة الثالثة

افتح `index.html` مباشرة. صفحة مستقلة بلا اعتماد على الإنترنت أو مكتبات خارجية.

الجزر مكوّنة من مجموعات خلايا سداسية، مع نمط سداسي أصغر داخل كل خلية. الضغط على جزيرة يقرّبها ثم يعرض الرواة في الخطوة التالية بمجموعات سداسية أخرى. أزرار + و− تغيّر التكبير البصري، بينما الضغط على اسم الراوي يفتح طبقة بيانات جديدة.

توجد روابط للواجهتين السابقتين، وشريط للمسار، ورجوع طبقة واحدة، وعودة إلى الصحابة. يدعم تقليل الحركة وإتاحة التنقل بلوحة المفاتيح.

البيانات هي المسارات الأولية الـ41 نفسها المستخدمة في خريطة الجزر، وليست تفريغاً كاملاً أو مراجعة حديثية. يعتمد تفرّع كل خطوة على بادئة المسار كاملة.

المرجع البصري: الصورة التي أرفقها المستخدم لواجهة Kinnu. الرسومات SVG أصلية، دون إيموجي أو استخدام أصول التطبيق.

التحقق: عرضا 390 و320 بكسل، التدرج من عائشة عبر عروة والزهري إلى مالك ثم يحيى بن قزعة، نهاية المسار والعودة، فرعا قتادة في مسار أنس، التكبير البصري، والانتقال إلى الجزر ثم الرجوع.
