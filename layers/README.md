# عرض كل خطوات السند

صفحة HTML مستقلة: `index.html`.

تظهر كل خطوات الأسانيد المتاحة، بما فيها الثالثة والرابعة حتى السابعة. الأرقام مواضع داخل السند، وليست طبقات تاريخية. اختيار راوٍ يقيّد النتائج بالأسانيد المطابقة له، ويمكن إعادة عرض كل المسارات.

«اختبر حفظك» يخفي أسماء الرواة بعد الصحابي؛ الضغط يكشف الاسم للمقارنة بما استرجعه المستخدم ذهنياً. لا تُحتسب درجة ولا تُحفظ نتائج. تُحجب قائمة الأسانيد الكاملة أثناء التمرين.

البيانات أولية، وهي الـ41 مساراً نفسها المستخدمة في الجزر. العرض العام يجمع الأسماء بحسب موضعها، ولا يعني أن كل اسم في صف متصل بكل أسماء الصف التالي. للتثبّت من اتصال سلسلة محددة، اختر راويها أو افتح قائمة المسارات الكاملة.

التحقق: اختيار مالك يعطي أربعة أسانيد وخمس خطوات، اختيار أسامة يعرض حتى سبع خطوات، إخفاء الأسماء وقائمة المسارات أثناء الحفظ، كشف اسم عروة، والعرض ضمن عرض هاتف 390 بكسل.
