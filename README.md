# Proof Norea

افتح `index.html` للبدء بخريطة الجزر. زر «قارئ الصفحة» ينقلك إلى صفحة الكتاب، وزر «خريطة الجزر» يعيدك إلى الجزر.

الروابط نسبية وتعمل عند فتح الملفات مباشرة دون إنترنت أو تشغيل خادم.

- `islands/index.html`: جزر الصحابة والتنقل في طبقات الرواة.
- `poc/norea-page.html`: قارئ الصفحة المتجاوب، ملف مستقل.
- `poc/index.html` و`page-data.js` و`reader.js` و`assets/`: مصادر القارئ.
- `poc/build-standalone.py`: إعادة بناء ملف القارئ المستقل بعد التعديل.

تضم وثائق كل قسم تفاصيل النموذج وحدود دقة النصوص والمسارات المنقولة من الصور.

## الواجهة الثالثة

`honeycomb/index.html`: عرض الصحابة والرواة بجزر مكوّنة من خلايا سداسية، مع التقريب إلى طبقات سداسية متكررة. متاحة من أزرار التنقل في القارئ والجزر.

## عرض كل الطبقات

`layers/index.html`: جميع خطوات السند، مع تصفية المسارات بحسب الراوي وإخفاء الأسماء لاختبار الحفظ. متاح من أزرار التنقل في الواجهات السابقة.

## الأطلس وشجرة السند

`atlas/index.html`: خريطة تسحب بالاتجاهين وتكشف الفروع عند عتبة تكبير.

`tree/index.html`: شجرة سند تتمدد مع فتح الرواة حتى نهاية المسار.
